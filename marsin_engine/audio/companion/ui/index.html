engine sync: —
① Set gain for when an art car / loud source is near (so LOW·MID·HIGH look good, no clipping). ② At your quiet baseline (no loud source — needn't be silent) tap Calibrate noise floor: LOW·MID get gated cleanly. ③ When a loud source returns, nudge the HIGH gate down — highs don't carry over distance, so they need this last touch.
①
Calibrate noise floor
Run this at your quiet baseline — whatever's normal when no loud source (art car) is nearby. It does not need to be silent. Listens for ~4 s and sets each band's gate to reject that ambient, so quiet moments stay calm while louder music clears the gate. Set the gain first (→) so the gate matches the level you'll run.
recommended → — low · — mid · — high
②
Calibrate gain
Do this when a loud source (art car) is near, at a typical loud level. Recommends an input gain so loud music sits healthy (not clipping). Set this before the noise floor — gain and the gates are linked, so changing gain a lot afterward means re-calibrating the floor.
