## What shipped

The live-busking accent: HOLD a channel's **BUMP** button → that channel slams
to FULL output (capped by `faderMax`); RELEASE → snaps back to its parked
level. Server-authoritative, transient, allocation-free hot path — directly
analogous to the existing solo `Set`.

### Engine

- **`pattern_mixer.js`** — `_bumpedChannelIds` Set; `bumpChannel(id)` /
  `unbumpChannel(id?)` / `clearBumps()` (fail-loud 404 on bad id; never mutate
  fader/enabled). Bump override is the first branch in `_effFader` after the
  hard-mute gate: `if (bumped) return min(1.0, faderMax)` — overrides own fader
  + group scale + solo-dim so the accent always reads, BUT a hard mute
  (`enabled=false`) still wins and the `faderMax` safety ceiling still caps it
  (a CAP fixture is never over-driven). Gated `_bumpedChannelIds.size > 0`
  short-circuit keeps the no-bumps case ~free. Cleared on
  `removeMixerChannel` / `triggerMixerTransition` / teardown / `panicToSafeDefault`.
- **`api_server.js`** — `POST /mixer/channels/:id/bump { on }` armed BEFORE the
  `^/mixer/channels/[^/]+$` regexes (next to `/duplicate`); WS `bump`/`unbump`
  handlers + `bumpRejected` push-back; `bumpedChannelIds[]` in
  `serializeMixerState` (rides the existing `mixer` broadcast, like solo; NOT
  persisted). **Release-on-disconnect: TWO nets** — (1) a 2 s per-channel
  **lease** renewed by the client's hold-heartbeat, swept every 500 ms
  (`unref`'d, armed only while bumps held); (2) **ws-close** releases the
  channels that socket bumped (`ws._bumpedByThisWs`). REST-only bumps rely on
  the lease (no socket).
- **`ws_topic_routing.js`** — `bumpRejected` → `/ws/control`.

  unmount cleanup clears timers AND eagerly releases held bumps.

## Semantics (decided + documented)

- Bump TRANSIENT (not persisted; empty after restart) — like solo.
- While bumped: effective output = `min(1.0, faderMax)` (overrides fader + group
  + solo-dim; faderMax ceiling still holds). `enabled=false` (hard mute) wins.
- Release-on-disconnect: lease (~2 s, renewed ~700 ms) + ws-close. Documented.
- No silent fallback: bad/deck/unknown id → 404/400; non-boolean `on` → 400.

## Notes / deferrals

- Bump rides the `mixer` broadcast (no dedicated broadcast type) — matches
  solo. A dedicated low-latency `bump` broadcast was considered but adds wire
  surface for negligible gain; deferred.
- Optional per-GROUP bump (bump every member of a group) was in scope as
  "optionally"; deferred to keep the slice tight + the hot path minimal. The
  per-channel primitive composes (a group bump = bump each member id) and can
  layer on later without touching `_effFader`.
- Pre-existing unrelated dirt in `states/summer_camp_dome/*` and
  `simulation/scenes/summer_camp_dome/playlists/default.yaml` was present in the
  worktree (not from this work, not engine-written by the test_bench HIL run) —
  left untouched and NOT committed.
