## #9 — sACN-IN auto-subscribe to patched universes

**Files:** `simulation/src/dmx/patch_manager.js` (+ test).

The sharp edge lived in `patch_manager.js`. `_validatePatchUniverses` compared
the patch-referenced universes against the *static* `params.sacn_universes`
config string and, on any universe not in that list, raised the loud red
`UNIVERSE MISMATCH` banner with manual remediation steps. The browser sACN-IN
source (`sacn_input_source.js`) already auto-adds router universes on the first
frame; the gap was purely the subscribed-universe **config/validation** set
never tracking the patches.

**New seam (in `patch_manager.js`):**
- `deriveSubscribedUniverses(fixtures)` — the authoritative union of every
  universe the current patches reference: DMX fixtures (`params.parLights`,
  passed in) **and** LED strands (`params.ledStrands`, read from live state).
  Sorted, deduped, positives only.
- `autoSubscribePatchUniverses(fixtures)` — merges any patch-referenced
  universe not already in `params.sacn_universes` into it, refreshes the
  `sacn_universes` GUI control via `updateDisplay()`, logs the additions
  loudly, and re-notifies the bridge (`saveAndNotify`). Returns the
  newly-added universes (idempotent — `[]` when nothing changed).
- `recompute()` now calls `autoSubscribePatchUniverses(fixtures)` **before**
  `_validatePatchUniverses(fixtures)`. So a normally-patched model just lights
  up; the mismatch banner only fires if a universe genuinely could not be
  subscribed (no silent failure — codex P0). `_validatePatchUniverses` was
  also widened to count LED-strand universes (was fixtures-only) via the
  shared `deriveSubscribedUniverses`.

This is re-derived on every patch change (boot scene-load, Test Auto-Patch,
manual edits) because `recompute()` is the single funnel all those paths call.

**Note:** a pre-existing `setInterval(recompute, 10000)` safety poll at module
top-level kept the Node test process alive; it is now captured and `.unref()`d
(guarded `typeof … === 'function'` so the browser's numeric-id `setInterval`
return is a no-op). Behaviour unchanged in the browser.
