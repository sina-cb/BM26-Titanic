## Engine behaviour (as built)

`POST /deck/focus { channelId }`:
- `null`/absent ⇒ clear ⇒ 200 `{ status:'ok', deckFocusChannelId:null }` (restores canonical deck view).
- non-string `channelId` ⇒ 400.
- the deck channel's own id ⇒ 400 (deck cannot cue itself).
- unknown id ⇒ 404.
- valid overlay ⇒ set `mixer.deckFocusChannelId`, broadcast, 200.
- Placed as a `/deck/*` exact-match arm BEFORE the `/mixer/channels/:id` regex arms.

`deckFocusChannelId` surfaced on `GET /deck/channel` and `serializeDeckState`
(deck WS broadcast). Transient: not persisted, clears on engine restart.
