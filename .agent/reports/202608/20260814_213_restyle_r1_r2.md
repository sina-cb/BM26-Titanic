## 2. R2 — workspace chrome + rail

**The single biggest visible change, exactly as the design predicted.** Before
this slice PATTERNS was a `leftPane` pane while PARAMETERS / AUTOPILOT /
COLORS were bare transparent scroll columns with floating cards. Now all four
`<DeckWindow>` tracks take the same `globalStyles.panel` recipe — fill +
hairline + inset top highlight (dark bases) + ambient shadow — so the Deck
reads as a set of instruments.

- **Rhythm:** each track carries `marginHorizontal: 4` and the columns host
  `paddingHorizontal: 4`, giving an 8pt gutter everywhere. Column WEIGHTS are
  untouched (`workspace.flexFor`), as is the narrow PATTERNS flexBasis pin.
  A 12pt gutter was tried first and rejected — see §4.
- **Window identity colours** (docs/54 §3, operator's proposal implemented):
  PATTERNS `primary` · PARAMETERS **MIDI violet** (`constants/identity`) ·
  AUTOPILOT `tertiary` · COLORS a **live C1/C2 `DualSwatch`** driven by the
  same `useSharedParamValues({colorPalette1, colorPalette2})` slice the COLORS
  window reads (a read-only broadcast subscription, zero traffic). The dot is
  the SAME whether the window is open or hidden, so closed→open reads as one
  object moving.
- **Chip grounds:** HIDDEN chips are the design's quiet paint
  (`surfaceContainerLowest` + `ghostBorder` + `microCaps`); OPEN chips wear
  `surfaceContainerLow` — literally their window's own `panel` surface —
  plus `borderStrong` and `labelCaps`. Slice A had these the other way round
  (open on lowest, hidden on High), which made the single hidden chip the
  loudest thing on the bar.
- **HIDDEN divider** → `borderStrong` (it is a real boundary; `ghostBorder`
  vanished against the bar), caption → `microCaps` in `icon`.
- Radii → `Radius.control`, gaps → `Space`. Touch targets, hitSlop, a11y
  labels, `accessibilityState`, the PATTERNS static-chip rule and the
  no-remount `display:'none'` contract are all untouched.

**Why open chips are NOT `surfaceContainerHigh`:** MIDI violet is a frozen
identity hex and measures **2.67:1** on gruvbox's `surfaceContainerHigh` —
under WCAG 1.4.11's 3:1 for a UI component. On `surfaceContainerLow` every
window dot clears 3:1 on all five themes (gruvbox violet is the binding case
at 3.02). Pinned by a test, with the rejected ground pinned too.

## 3. Contrast work

New file **`components/restyle_contrast.test.ts`** (9 tests) — R0 pinned the
tokens, this pins the *call sites* R1/R2 created:

1. `tertiary` as TEXT on every surface of every dark-base theme (≥4.5).
2. `accentWash(primary|tertiary|warning)` ink over the three grounds the deck
   actually composites washes on — `background` (the header row),
   `surfaceContainerLow` (a window panel), `surfaceContainerLowest` (a card).
   The sweep is deliberately narrower than R0's six-surface sweep and the
   file says why: `surfaceContainerHigh` and `surfaceDim` are not wash grounds
   on this screen, and asserting them would fail on pairings the code cannot
   render (light `warning` wash on Dim is 4.4987 — rounding).
3. The three window identity dots ≥3:1 on BOTH chip grounds, all five themes,
   plus the explicit "surfaceContainerHigh is rejected because violet fails
   there" assertion and a dots-are-distinct check.
4. The plan-lock banner's `warning` FIELD ≥3:1 on every surface — the field is
   what defines that floating banner's edge (its inner rule is decoration).

**`components/design_tokens.test.ts`** — one R0 assertion legitimately moved.
The "panic amber matches the shipped plan-lock banner" anchor pointed at
`PLAN_LOCK_AMBER`, which R1 deleted when the banner went theme-aware. It is
replaced by two stronger guards: the deck screen must import `PANIC_AMBER`
by name and must not re-spell the hex; and the banner must carry `C.warning`
+ `readableInk()` and none of the six literals R1 retired.

### FINDING — `light.tertiary` cannot clear AA as text (operator decision needed)

The docs/54 mapping `#00a86b → tertiary` has a hole on the **daylight
palette**. `light.tertiary` is `#1b9e77`, measuring **2.42–3.39:1** across the
six surfaces — below AA for the CONNECTED label, the MIDI chip label, the
◎ ALL pill and the AUTOPILOT live wash. It is visible in
`after/deck_default_wide_light.png` (the pale-green PAUSE).

- **R1 did not cause it and made every site better:** the literal it replaced
  measured **2.20–3.08** on the same surfaces. Nothing regressed.
- **The fix is a `constants/theme.ts` VALUE change**, which this slice is
  explicitly not allowed to make (R1 consumes tokens, it does not re-tune
  them). `'#0d5c44'` clears both bars on the light palette — **5.70:1** direct
  and **4.64:1** as wash ink on the worst surface — if a one-line fix is
  wanted. All four dark-base themes are already comfortably clear (5.62–10.76).
- The gap is **pinned** in `restyle_contrast.test.ts` as an explicit,
  documented exception that also floors it at "never worse than the literal it
  replaced". When `light.tertiary` is fixed, that test FAILS on purpose so the
  exception gets deleted rather than forgotten.

## 4. Forced markup changes (3, all minimal, all justified)

1. **`EntryLabelEditor` gained a `focused` boolean.** docs/54 row 8 asks for a
   `borderStrong` focus ring; RN has no `:focus`. `onFocus` sets it; `onBlur`
   clears it **and still calls the same `commit()`**. The debounce → onBlur →
   native-DOM-blur → unmount-flush autosave chain is byte-for-byte unchanged.
2. **Both autopilot header clusters gained `flexWrap` + `rowGap: 6`.** The
   identity dot costs that row ~18pt, and in the all-four-windows-open
   landscape layout the shrinking cluster clipped "PAUSE" to "PAUS". The
   cluster now wraps the transport onto a second line instead of cutting it —
   and only in the widths where it would have been cut. (`flexShrink: 0` on the
   button alone was tried first and was not enough; both are in place.)
3. **The R2 gutter is 8pt, not 12pt.** Window chrome costs horizontal room and
   the all-open 1194pt landscape is the binding case — 12pt gutters clipped the
   AUTOPILOT transport. docs/54 §6 decision 5 says the restyle preserves
   current compactness, so the gutter yields, not the control.

Everything else is style-value substitution in place.
