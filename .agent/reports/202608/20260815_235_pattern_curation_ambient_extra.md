## Integration fixes found by the gallery

The first gallery render correctly failed instead of inventing missing saved
values:

- `15_woven_light`: `sliderThreadWidth` wrote a private live variable, so the
  shared default parser could not connect the slider to its exported default.
  The control now authors `threadWidth` directly.
- `25_zipper_light`: `sliderDirection` assigned its transformed temporary
  before the exported input, so the default parser resolved the wrong variable.
  The exported 0..1 value and internal signed direction are now explicit.

`tests/patterns/ambient_extra_contract.test.js` permanently pins slider-default
resolution across all 50 sources so this class of failure cannot recur.
